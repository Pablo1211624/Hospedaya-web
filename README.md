# HospedaYa
Aplicación web que almacena publicaciones y reservaciones de alojamientos temporales.

El proyecto está inspirado en la plataforma Airbnb y permitirá gestionar usuarios, alojamientos, disponibilidad y reservas desde una aplicación web.

## Tecnologías

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM

### Base de datos
- PostgreSQL
- Docker
