# HospedaYa
Aplicación web que almacena publicacine y reservación de alojamientos temporales.

El proyecto está inspirado en la plataforma Airbnb y permitirá gestionar usuarios, alojamientos, disponibilidad y reservas desde una aplicación web.

## Tecnologías

### Frontend
- React
- Javascript

### Backend
- Node.js
- Express
- Javascript

### Base de datos
- PostgreSQL 16
- Docker
